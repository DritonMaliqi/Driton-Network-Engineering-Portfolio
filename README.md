## Troubleshooting Workflow

1. Define the exact failing service.
2. Identify the source and destination.
3. Build the expected packet path.
4. Start testing from the endpoint.
5. Stop at the first failed boundary.
6. Collect evidence before changing configuration.
7. Change one variable at a time.
8. Repeat the original failed test.
9. Verify related services and the return path.
10. Document the root cause, resolution, and preventive action.
