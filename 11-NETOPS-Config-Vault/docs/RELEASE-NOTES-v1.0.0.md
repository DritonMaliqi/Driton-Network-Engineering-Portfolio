# NETOPS Config Vault v1.0.0 – Release Notes

Release date: September 2026  
Status: Completed

## Included

- Bilingual English/Albanian Tkinter interface
- Local SQLite configuration history
- Device-name detection
- SHA-256 version fingerprints
- Duplicate backup prevention
- Version-to-version change analysis
- Operational risk classification
- Unified diff and text report export
- Windows executable and Desktop shortcut automation
- Lab-safe Cisco IOS sample configurations
- Automated tests for the core engine and database

## Scope

Version 1.0.0 uses imported or pasted configuration data. It does not connect directly to network devices and does not make configuration changes.

## Future Candidates

- SSH collection through Netmiko
- Encrypted credential storage
- Scheduled backup jobs
- Multi-vendor parsers
- HTML/PDF reporting
- Approved rollback snippet generation
