# NETOPS AI v3.1

Status: Completed  
Platform: Windows 10/11  
Runtime: Python 3.13

## Highlights

- Rule-based offline analysis for common CCNA/CCNP incidents.
- Automatic device-name detection.
- Structured symptom, evidence, verification, minimal-change and retest output.
- Two-device comparison for OSPF, BGP, subnets, trunks and EtherChannel.
- Local SQLite incident history with ACTIVE/RESOLVED workflow.
- Printable HTML report export.
- Standalone Windows executable build and branded desktop shortcut.

The analyzer unit-test suite passes all included test cases. The Windows executable, persistent incident history, report export, device comparison and shortcut were manually validated on Windows.
