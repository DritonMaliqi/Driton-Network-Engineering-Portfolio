# NETFORGE Network Lab Generator

## Project 17 - CCNA / CCNP Troubleshooting Lab Generator

NETFORGE Network Lab Generator is a Python-based training platform for practicing realistic network troubleshooting scenarios.

## Features

- CCNA and CCNP tracks
- Easy, Medium and Hard difficulty levels
- VLAN troubleshooting
- Trunk troubleshooting
- DHCP troubleshooting
- OSPF troubleshooting
- Interactive troubleshooting console
- Cisco-style simulated outputs
- Troubleshooting hints
- Root-cause and corrective-action scoring
- Multi-fault Hard Mode
- Automatic lab documentation

## Interactive Console

Supported commands include:

- show vlan brief
- show interfaces trunk
- show ip route
- show ip ospf neighbor
- show ip ospf interface brief
- show running-config
- ping

Special commands:

- help
- history
- hint
- diagnose
- exit

## Hard Mode

Hard Mode supports multiple simultaneous network faults.

Examples include VLAN access-port mismatches, missing trunk VLANs, OSPF area mismatches, and missing OSPF network advertisements.
