# NETOPS IPAM v1.0.0 – Release Notes

Release date: September 2026  
Status: Completed

## Included

- Bilingual English/Albanian Tkinter interface
- IPv4/CIDR calculator
- Equal-size subnet generator
- Largest-requirement-first VLSM allocator
- SQLite-backed IP allocation inventory
- Duplicate IP protection and input validation
- Search, CRUD operations, CSV import and CSV export
- Windows EXE and Desktop shortcut automation
- Fictional network inventory sample
- Automated tests

## Scope

Version 1.0.0 manages IPv4 planning and inventory locally. It does not scan production networks or change device configurations.
