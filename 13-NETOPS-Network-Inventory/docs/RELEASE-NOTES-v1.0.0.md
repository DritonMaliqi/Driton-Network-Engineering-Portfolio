# NETOPS Inventory v1.0.0 – Release Notes

Release date: September 2026  
Status: Completed

## Included

- Bilingual Tkinter interface
- Network asset dashboard
- SQLite inventory with uniqueness and input validation
- Search and status filtering
- CSV import/export
- Standalone HTML report generation
- Windows EXE and Desktop shortcut automation
- Fictional sample inventory
- Automated tests
- Correct selection loading for read-only device-type and status fields

## Scope

Version 1.0.0 provides local manual inventory and documentation. It does not scan devices, store credentials, or modify network configurations.
